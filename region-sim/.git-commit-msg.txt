修两处：季末清仓并入 X_t 求价 + H 中段斜率写明

一、季末清仓并入 X_t（修一个可套利漏洞）

漏洞原状：清仓卖的货没有算进本季总供给。玩家只要 sales 里什么都不申报，
第 7 步就不求价，清仓回退【上季价】卖掉 —— 等于往市场砸一大堆货而价格不动。

修法：求价前先按【数量】推算清仓量并进 X_t：
  X_t = 申报卖出 + 清仓量
  清仓量 = 可供出售 − 申报卖出 − 居民吃掉

这里【没有循环依赖】：居民吃多少只看数量、不看价格
（§4.3.7 已作废预算约束 D_实 = min(D, B/k)），
所以能在求价前先把扣减推算出来。

- settlement.py：抽出纯函数 plan_food_deduction()，使"预估清仓量"与
  "实际扣减"走同一套口径；settle_food() 改为它的执行包装
- pipeline.py：第 4.5 步预算清仓量并进 X_t；第 7.7 步不再有回退上季价分支，
  拿不到价就明确报错；Report 新增 planned_clearing
- 实测：一批 3.6 单位 F，"不申报"与"全申报"现在求得同一个价 23.568
  （此前会按 24.0 清掉）

二、H 中段斜率写明（用户确认中间线性）

  F_优秀 = 1.5 × F_基准
  下段斜率 = 0.6 / F_基准
  中段斜率 = 0.4 / (0.5 × F_基准) = 0.8 / F_基准     ← 是下段的 4/3

  例：F_基准 = 2.0 → 下段 0.300、中段 0.400，
      中段从 (2.0, 0.60) 直线到 (3.0, 1.00)
