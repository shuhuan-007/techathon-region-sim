# web/assets/icons/ —— glb 加载失败时的 2D 降级图

> 当 `web/assets/plots/<key>.glb` 在网络 404、超时、解析失败等任何场景下无法使用时，前端在地块位置上改画这里的同名 SVG；不弹错、不阻塞其它格。
> 本目录只作"降级图"用途，不追求与 glb 视觉一致。

## 一、已抽出的 SVG（共 14 个）

## 三、来源声明

- 源文件：[`region-sim/web/prototype-v0.html`](../../prototype-v0.html)（行 698-1047 `const ART`，行 696 `const A = ...`）。
- 抽取时间：2026-10-17。
- 抽取方式：手工按 key 拆出模板字符串内容，加 `<?xml version="1.0" encoding="UTF-8"?>` 头 + 自封闭 `<svg>` 根。**未修改 prototype-v0.html 本身**。
- ⚠️ 小改动：部分 SVG 文件里含原型的 HTML 注释（如 `<!-- 高炉 -->`、`<!-- 多层楼宇 -->`）——保留作为阅读说明，不影响渲染。

## 四、使用方式

glb 加载失败时作为该地块的 2D 降级图。
