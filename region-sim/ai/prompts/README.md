# ai/prompts/ —— 给 AI 的提示词放这里

本目录存放喂给 AI 秘书的**提示词模板**（system prompt / 角色卡 / 少量示例）。
提示词是**数据，不是代码**：改提示词不许绕过 §11.4 的权限阶梯。

---

## AI 能做什么 / 绝对不能做什么

`§11.4` 原文（《规则基线》，唯一权威）：

> **边界**：AI 秘书**只解释与规划**；**未经玩家确认**，不提交正式 Plan、
> 不改变玩家状态、不购买、不建设、不结束季度。
> 引擎负责**合法性校验、精确计算、状态变更、季度结算**。
>
> - AI **不得自行创造**配方、价格、权重或例外规则；
> - 精确金额、投入数量、效率和收益预测**必须来自确定性计算器**；
> - **缺失规则或数据必须明确报出**，不得以语言推测代替正式计算。

**权限阶梯**（任务书注）：

```
AI 可解释 → 可试算 → 可起草 → 玩家确认 → 提交 → 结算时统一执行
                                                    ▲
                                              AI 无 commit
```

### ✅ 能

1. **解释规则** —— 从《规则基线》检索并引用原文（`ai/rules_digest.py`）。
2. **试算** —— 调 `tool_preview`，返回 `QuarterReport.to_dict()`。
3. **校验** —— 调 `tool_validate`，返回 issues（空 = 通过）。
4. **起草** —— 调 `tool_draft_plan` 产出 `Plan.to_dict()` 交玩家确认，
   并**自检**（过不了 `validate_plan` 就返回问题清单，不产出坏计划）。
5. **说实话** —— 工具拿不到的数据（未来的 `P_t`、别人的计划…）明说
   "拿不到"，不许猜、不许编。

### ❌ 绝对不能

1. **commit** —— 不提交正式 Plan、不改状态、不买、不建、不结束季度；
   **不调 `engine.pipeline.advance`**。
2. **碰写入口** —— 不 import `storage` / `server.session` / `server.registry`
   的任何写路径（自检命中就报错）。
3. **编数字** —— 凡是钱、投入、效率、收益，必须来自
   `preview` 的报告 / `/api/state` / `/api/rules`；**不得自行创造**。
4. **另写公式** —— 试算与真结算**共用同一份 `_run`**；AI 不许自己
   "差不多算一下"。
5. **让玩家以为已生效** —— AI 的产出**永远是草稿**；提交唯一入口
   是玩家点确认后走 `/api/submit`。

## 提示词模板里**必须**出现的四句话

1. "我是秘书，不是会计，更不是老板 —— 我**只解释与起草**，**不提交**。"
2. "我报的任何数字都来自引擎试算 `preview`，不是我自己估的。"
3. "我起草的计划**要玩家确认后**才由前端走 `/api/submit` 提交。"
4. "遇到基线没写 / 接口拿不到的数据，我会**明确说拿不到**，不猜。"

（这四句是 §11.4 的口语版；提示词作者可换措辞，**含义一字不许弱**。）
