## 一、30 秒跑起来

**前提**：装了 Python 3（3.10+ 即可），**不需要** `pip install` 任何东西。

```powershell
# ① 进项目根（必须！cwd 不在 region-sim 会找不到 engine/config/saves）
cd D:\开发特区\region-sim

# ② 启动服务（默认 127.0.0.1:8000）
python server/app.py

# ③ 浏览器打开
#    http://127.0.0.1:8000/
```

启动成功时控制台会打印：

```
============================================================
区域发展模拟 —— 服务已启动
  地址：http://127.0.0.1:8000/
  存档：D:\开发特区\region-sim\saves
  Ctrl+C 停止
============================================================
```

**一键版**：双击 `D:\开发特区\region-sim\start.bat` —— 它会起服务、等 3 秒、自动打开 `http://127.0.0.1:8000/`。

### 常用变体（都是代码里真实支持的）

```powershell
# 换端口（8000 被占时；本机实测 8211 空闲）
python server/app.py --port 8211
# 打开 http://127.0.0.1:8211/

# 换存档目录（默认就是 region-sim\saves）
python server/app.py --saves saves

# 强制离线：不真调模型（叙事/建议秒回"不可用"，数字与结算完全不受影响）
python server/app.py --offline

# 两种启动写法都支持（脚本内已做 sys.path 兜底）
python -m server.app
```

> ⚠️ 不要用 `python -m http.server` 之类静态服务器代替 —— 页面能开，但 `/api/*` 全 404，一局都开不了。

## 二、五个常见故障与处理

### 1. 端口被占用（`OSError: [WinError 10048]` / 启动即退出）

**现象**：控制台立刻报 `Address already in use` / `10048`，或页面打不开。
**处理**：换端口，**只改启动命令，不改代码**。

```powershell
python server/app.py --port 8211
# 然后浏览器开 http://127.0.0.1:8211/
```

**先查是谁占着**（可选）：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 8000 | Select-Object LocalPort,OwningProcess
Get-Process -Id <上面查到的PID>
```

> 实测记录：`8000` 空闲、`8211` 空闲、`8300` 当时被另一进程占用 → 换端口优先用 **8211**。

### 2. 没有 `.env`（离线模式）

`.env` **不是启动必需**：它只承载 AI 层配置（`AI_BASE_URL` / `AI_MODEL` / `AI_TIMEOUT` / `AI_API_KEY`），服务本身、数值引擎、2D 界面、结算、存档全都不读它。

- 没有 `.env` → 服务照常起，**数字全对**；只有「AI 秘书建议」「新闻/财报叙事」会失败（返回 `ok:false` 并写明原因，**不会编造数字**）。
- 演示只想走「数字 + 结算」：直接加 `--offline`，省掉等模型的几十秒。
- 想要 AI 上场：把 `.env` 放回 `region-sim\.env`（格式 `KEY=value`，一行一个），或现场设环境变量（环境变量优先于 `.env`）。

### 3. 3D 资产（`.glb`）缺失时前端如何退化

**先说结论：主界面不受影响。** 2026-10-18 起主地图是**纯 2D 格子**（3D 渲染层已从 `web/js/map.js` 整段删除），glb 只在「城市详情弹窗」里用。

- `.glb` 404 / 加载超时（前端 15s 超时）→ 控制台 `console.warn`，弹窗静默跳过该模型，**格子保持 2D 渲染**，页面其余功能照常。
- `three.min.js` / `GLTFLoader.js` 缺失或没加载 → `console.warn('[cityModal] THREE 或 GLTFLoader 未加载 — modal 关闭')`，弹窗关掉，主流程继续。
- 需要 3D 时把 `web\assets\plots\*.glb`（实测 21 个，约 533 MB，**未入 git**）拷回原位即可；这些文件不在运行时校验里，缺了不会阻止启动。

### 4. 存档不存在时怎么开局

`GET /api/games` 返回空数组、或 `GET /api/state?game=xxx` 返回 **404**（`存档不存在`）时，说明 `saves\` 里没有这一局。三种开法：

```powershell
# A. 页面上直接「新开一局」（前端走 POST /api/new_game）
# B. 命令行新开一局（默认 game_id=g1、player_id=p1）
curl.exe -X POST http://127.0.0.1:8000/api/new_game -H "Content-Type: application/json" -d '{\"game_id\":\"demo\",\"player_id\":\"p1\"}'
# C. 读已有存档位（slot）为新局
curl.exe -X POST http://127.0.0.1:8000/api/load_slot -H "Content-Type: application/json" -d '{\"slot_id\":\"demo@q3\",\"as_game_id\":\"demo-replay\"}'
```

- 换一个干净的存档目录重开：`python server/app.py --saves saves_demo`（目录不存在会自动建）。
- 注意：`saves\` 里现有的 `finale_*` 系列是**终局界面验收档**（`total_quarters=2`，第 3 季），**不是**正常 20 季演示局，别拿它演完整流程。

### 5. 浏览器缓存（改了看不到 / 还是旧界面）

- 服务端**所有响应都带 `Cache-Control: no-store`**（HTML/JS/CSS/API 一致），正常情况下不会吃到旧缓存。
- 前端脚本自带版本号（如 `city-modal.js?v=2`），改版后 URL 会变。
- 仍不对：**Ctrl+F5 强刷** → 无痕窗口开一次 → F12 看 Console/Network 有没有 404。
- 无痕窗口还不对，就不是缓存问题，去看服务端控制台的第一行报错。

## 三、现场 Demo 五步走（< 3 分钟）

> 数字口径：**① ② ⑤ 的金额/季数/地块数**为 `演示操作稿.md` 2026-10-17 的 HTTP 真跑实测（game=demo2）；**③ 的 AI 台词行为**引自 `DEMO剧本-玩法展示版.md` Q3 示例。**不要临场改数字**。

| 步 | 你做什么 | 评委看到什么 | 耗时 |
|---|---|---|---|
| **① 开局** | 页面点「新开一局」（`POST /api/new_game`） | **现金 1200.0、第 1/20 季、地块 0**，10×10 全可建空地；秒开 | 0.02s |
| **② 摆地块** | 点 (0,0)(1,0)(2,0)(3,0) 四块，建**农业 A**（产出必须选 A，建后不可换） | 提交后 `can_settle=true`、`settle_blockers=[]`；**关键**：提交瞬间现金仍是 **1200.0、地块 0** —— **提交只记忆、不扣款** | <0.01s |
| **③ AI 起草** | 右栏「AI 秘书」输入「**帮我起草一份再扩 2 块农业**」 | AI 回一段 summary，`suggested_plan` **自动落表**（多出虚线建造标记）；顶栏自动试算出一行「本季计划扣 X｜结算后约 Y」；**AI 只能建议、没有提交权** | 40–60s（等模型） |
| **④ 提交** | 点「▶ 推进本季度」（前端 `submit` → `end_quarter` → `next_quarter` 连走） | 流水逐条涌现（建造完工 / 生产 / 卖出 / 扣款 / GDP），月报弹窗自动弹出，季度切到 **2** | 0.02s + 0.03s |
| **⑤ 结算看月报** | 指着月报念这一季的账 | **现金 744.0**（1200 − 456）、**第 2/20 季**、**地块 4**；456 的拆解：现金 **40×3 + 80×1 = 200**（前 3 块半价，第 4 块恢复原价 80）+ 材料 **64×4 = 256**（材料不打折） | 叙事缓存则秒回 |

**两处必须提前串词的地方（全场只有这两处等模型）**：

1. **⑤ 的新闻/财报叙事**：`GET /api/state` **首次**触发生成两路叙事，实测 **134–181s**；同季第二次读走缓存秒回。
   → **彩排时先跑一遍把叙事写进缓存**，正式演示直接用缓存。没缓存就切去讲架构图，别干等。
2. **③ 的 AI 起草**：40–60s，备 40s 串词（讲「AI 是秘书不是老板：它只建议，提交永远是人」）。

**≤3 分钟能压住的前提**：叙事已缓存、AI 那步只用一次。若 AI 无法用（见 §四 的 key 问题），③ 改成「手点 2 块 + 讲 AI 的分工」，总额约 20 秒，五步照样成立。

## 四、离网兜底

**代码真实支持的开关**（`server/app.py`、`ai/narrate.py`、`server/llm_client.py`）：

| 变量 / 参数 | 真实取值与优先级 | 作用 |
|---|---|---|
| `NARRATE_OFFLINE` | `0` / `false` / `no` = 在线；**其它任意值 = 离线**；未设置时默认 **在线** | 全局叙事开关（新闻/财报/建议都不真调模型） |
| `--offline`（命令行） | 等价于把 `NARRATE_OFFLINE` 置 `1` | 最省事的离线启动 |
| `AI_BASE_URL` | 环境变量 > `.env` > 默认（OpenAI 兼容端点） | 换网关/本地代理 |
| `AI_MODEL` | 同上 | 换模型 |
| `AI_TIMEOUT` | 同上（秒） | 调大超时，防现场网络慢 |
| `AI_API_KEY` | 同上；**留空 = 不带 Authorization 头** | 鉴权 |

**离网（无外网 / 不想等模型）直接这样跑**：

```powershell
cd D:\开发特区\region-sim
$env:NARRATE_OFFLINE = "1"     # 或直接 python server/app.py --offline
python server/app.py
```

离线时：结算、地块、GDP、月报、存档**全部照常且数字一致**；只有叙事/建议两种文本变成「不可用（`ok:false`）」，前端如实提示、不编造。

**离网为什么能成立**：运行时零第三方 Python 包、无 CDN、无 webfont、无外链；3D 模型本地 `web/assets/plots/`。**唯一外网出口就是 AI API**（`server/llm_client.py` 一处）。所以断网 = 少两段文字，游戏本身完整。

> ⚠️ **现场发现（2026-10-18 实测）**：`region-sim\.env` 里只有 `AI_BASE_URL` / `AI_MODEL` / `AI_TIMEOUT`，**没有 `AI_API_KEY`**。按代码逻辑，请求将**不带鉴权头**，在线叙事/AI 建议预计被网关拒绝（返回 `ok:false`，页面会如实提示）。
> **对策**：现场想演 AI，先把 key 补进 `.env`（`AI_API_KEY=...`）或环境变量；补不上就 `--offline` 演「数字 + 结算」主线，AI 那步改讲设计（AI 只建议、无提交权）。
