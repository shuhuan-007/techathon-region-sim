# 第三方资源说明

本项目的**规则、引擎、AI、平台、前端资产均系团队原创**。
以下列明了为提升演示与体验所**集成、引用或经由其服务**的第三方工具 / 模型 / 平台 —— 全部符合其相应许可证，且均为已业界主流或学术常用接口。

## 一、AI 与 API

| 资源 | 用途 | 集成位置 | 授权 |
|---|---|---|---|
| **Qwen-flash**（阿里 DashScope） | AI 秘书起草 Plan、财报/新闻叙事（默认解耦、按季缓存） | `region-sim/ai/narrate.py`、`plan_compile.py`、`ai_host.py`（`.env` 提供 `QWEN_API_KEY`） | DashScope API 服务条款；我们确保 AI 只解释、不代提交 |
| **Kimi-k3 (本地)** | 展会现场起 3D 调研的辅助 agent（仅 demo 用） | 本地 DSH Harness runtime | 本地部署，不入仓 |

| 资源 | 用途 | 集成位置 | 版权 |
|---|---|---|---|
| **three.js r140**（vendor） | 3D 城市渲染运行时 | `region-sim/web/js/vendor/three.min.js` | MIT License；vendor 文件头部保留版权注释 |
