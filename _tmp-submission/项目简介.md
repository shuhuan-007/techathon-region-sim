# 项目简介

## 建设特区（Techathon 2026，区域发展模拟器）

> **桌游的悖论**：规则越复杂，世界越鲜活；世界越鲜活，新人越望而却步。
> 我们把 AI 秘书塞进桌游——让它替玩家读规则、起草计划、守住"不能替玩家做决定"的底线，
> 于是**原来只敢做轻量的模拟经营，现在可以放开往"复杂、拟真、好玩"那一端走**。

---

## 这是什么

一个**单人、20 季、无仓库、弹性市场**的区域经营模拟器。
玩家拥有一片 10×10 空地、1200 现金以及一位随身的 AI 秘书；从零开始摆地块、招人口、产商品、卖到市场、喂饱居民、抽政策、看月报——把一片荒地经营成有生机的城区。

**核心循环**：

```
行动阶段（提交计划）→ 季度结算（一次性扣款）→ 月报（新闻与财报叙事）→ 下一季
```

## 复杂在哪、好玩在哪

- **市场是真弹性的**：15 种商品、供需曲线求价、买入按上季价、卖出按本季价——你一次大手笔进货，价格会被你自己推高。
- **没有仓库**：产出即供给，本季度的粮食要本季度吃掉，吃不完的丢弃——每一个生产决策都必须精确。
- **幸福是复合型因果链**：粮食→幸福度→效率→产量，但效率反馈要用**上一季**的幸福度，不允许同时求解——逼玩家思考长周期。
- **政策是 25% 盲盒**：每季抽一张"生产激励 / 精益运营 / 民生优先 / 常规环境"，玩家要为环境变化留缓冲。
- **3D 城市与天空屏**：基建进度以 22 个手工建模 + 三维天空屏财报的形式**可视化呈现**——埋头经营 5 小时的人，点开 3D 城市那一刻，看到的不是一堆数字，是**自己建的一座城**。

## 上手难度怎么降下来

| 我们做的 | 它解决了什么 |
|---|---|
| **AI 秘书起手起草 Plan** | 不写规则书，新手开口就说"帮我安排这一季" |
| **AI 编译器+双闸** | 起草后先过 *validate*（不能违反规则）再过 *preview*（试算不能现金为负），才允许进玩家表单 |
| **AI 诚实** | 不认识的参数明说"给了就是编的"（实测原话），并把"提交权"还给玩家——AI 不能替你按下提交 |
| **前端零计算** | 玩家看到的所有数字都来自引擎；提交前的预览分毫不差地等于真实结算（测试已钉死） |
| **3D 建模 + 天空屏叙事** | 规则书的"邻接 +5%"、"幸福度 H=0.8"不再是文字，是你屏幕上 *looks alive* 的城市景观 |
