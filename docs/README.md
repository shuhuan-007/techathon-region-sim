## 阅读建议

- **只看结论**：`03-架构/项目架构-总.md` 的 §一～§三。
- **想核对某个数字**：`01-规范/规则基线.md` → 搜数字；再跑 `pytest tests/test_m1.py` 看断言是否一致。
- **想知道某条规则在哪一行代码**：`02-走查/已实现规则-流水账.md` 每节都标了文件与函数。
