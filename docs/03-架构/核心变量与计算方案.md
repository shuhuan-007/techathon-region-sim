# 核心变量一览

> 游戏里真正在变的那几个量：**是什么、被什么决定、影响什么**。
> 数据源《规则基线》。

---

## 总览：五个核心变量

```
        地块开发（建地、升级、开工）
                 │
                 ↓
  ┌──────────────┴──────────────┐
  ↓                             ↓
岗位 L                        效率 E
  ↓                             │
人口 N                          │
  ↓                             │
粮食需求 F                      │
  ↓                             │
幸福度 H ──────(下季)───────────┘
```

**一条主循环**：

```
你开发得越多 → 岗位越多 → 人口越多 → 要吃的越多
                                          ↓
                                    喂饱了吗？
                                     ↙        ↘
                                  喂饱        没喂饱
                                    ↓            ↓
                              H 高 → 下季效率高   H 低 → 下季效率低
                                    ↓            ↓
                                    └── 产出更多 / 更少 ──┘
```

**这就是整个游戏的引擎**：发展带来人口压力，人口压力决定你的效率，效率决定你能不能继续发展。

---

## ① 岗位 L（劳动投入）

| 项 | 内容 |
|---|---|
| **是什么** | 你这一季**实际雇了多少人** |
| **公式** | `L = Σ(所有开工地块: d × u)` |
| **被什么决定** | 地块的劳动 `d`、开工比例 `u` |
| **影响什么** | 人口 `N` |
| **范围** | 开局约 3–5，中后期几十 |

> `d` 是地块满负荷一季占的劳动量。**`L` 不乘效率 `E`** —— 效率高不代表人变多，只是同样的活干得更多。

**参考值**（1 级地块满负荷 `u=1`）：

| 农业 | 资源 | 工业 G | 服务 | 机械H/研究 |
|---:|---:|---:|---:|---:|
| 2 | 3 | 3 | 3 | 4 / 2 |

---

## ② 人口 N

| 项 | 内容 |
|---|---|
| **是什么** | 区域人口，**由岗位推出，不是外生给定** |
| **公式** | `N = L × 2`（✅ 2026-10-16 取消 `round`，保留小数） |
| **常量** | `r = 2`（总人口 / 劳动力比例） |
| **被什么决定** | 岗位 `L` |
| **影响什么** | 粮食需求 `F`、服务需求 |

**这个变量的意义**：你**开发多少，就有多少人来**。不主动开发，人口就不涨。
**它是"发展的结果"，不是"发展的资源"** —— 和一般经营游戏反过来。

| 岗位 L | 3 | 5 | 11 | 25 | 50 |
|---|---:|---:|---:|---:|---:|
| **人口 N** | **6** | **10** | **22** | **50** | **100** |
| 典型局面 | M1 单块地 | 农+服开局 | 4–5 块地 | 中等区域 | 后期大区 |

> `r = 2` 的含义：**一个劳动力养 2 个人**。
> 这个数直接决定"人口压力"有多重——`r` 越大，同样开发度下要喂的嘴越多。

> ⚠️ **不取整（2026-10-16 定案）**：`L` 与 `N` **都保留小数**——`u` 是 0–1 的比例、`d` 本身有 `1.5 / 2.5`，
> 所以 `L` 天然带小数。**引擎一律存小数**（否则账对不上），**取整是显示层的事**（界面上不出现"1.5 人"）。
> 原写法 `N = round(L × 2)` 作废（见基线 §3.3.1）。

## ③ 粮食需求 F

| 项 | 内容 |
|---|---|
| **是什么** | 这一季**要让居民吃饱/吃好，需要多少粮** |
| **公式** | `F_基准 = (N/5) × m`<br>`F_优秀 = 1.5 × F_基准` |
| **被什么决定** | 人口 `N`、**地块平均等级** `ḡ` |
| **影响什么** | 幸福度 `H` |

### 等级乘数 m

```
ḡ = 所有开工地块的平均等级（含服务/研究；不含空地、在建）
m = 1 + 0.15 × (ḡ − 1)
```

| ḡ | 1.0 | 2.0 | 3.0 |
|---|---:|---:|---:|
| **m** | **1.000** | **1.150** | **1.300** |

**为什么需要它**：产业升级了，居民生活水平期望跟着涨。**发展不只是"人多"，还"嘴刁"** —— 这是第二重压力。

### 两档要的东西不同（关键）

| 档位 | 需要 | 含义 |
|---|---|---|
| **基准** | **A、B** | 吃饱。**必须都有，且可互换** |
| **优秀** | **A、B、C、D** | 吃好。**四样全要** |

配比：`A 0.4 / B 0.2 / C 0.1 / D 0.02`（每单位篮位）

**基准档判定**（最易写错）：

```
R = 0.6 × F_基准
S = min(A投放, 0.4×F_基准) + min(B投放, 0.2×F_基准)

必须：A 或 B 有一个是 0 → 不达标（单靠一样顶不上）
可替换：各自配额上限内互补，S ≥ R 即达标
```

例（`F_基准 = 2.0`）：`A0.8/B0.4` ✅ ｜ `A1.2/B0` ✅（A 补 B）｜ `A0/B1.2` ❌

## ④ 幸福度 H

| 项 | 内容 |
|---|---|
| **是什么** | 居民满意程度，**0–1 的连续量** |
| **公式** | 由实际达成的 `F` 在两档之间插值 |
| **被什么决定** | **只有粮食**（服务不影响） |
| **影响什么** | **下季**效率 `E_幸福` |

```
H = 0.6 × (F / F_基准)                            , F < F_基准
H = 0.6 + 0.4 × (F − F_基准) / (F_优秀 − F_基准)  , F_基准 ≤ F < F_优秀
H = 1.0                                           , F ≥ F_优秀
```

| F / F_基准 | 0 | 0.5 | **1.0** | 1.2 | **1.5** |
|---|---:|---:|---:|---:|---:|
| **H** | 0.00 | 0.30 | **0.60** | 0.76 | **1.00** |

**两个锚点**：吃饱 → `H = 0.60`；吃好 → `H = 1.00`。中间平滑。
**初始值** `H₀ = 0.6`（开局既不奖也不罚）。

> **H 是"结果"不是"输入"**：它是被粮食决定的，不反过来决定要吃多少。
> 这个单向关系很重要——反过来会形成循环依赖，程序算不出来。

## ⑤ 效率 E

| 项 | 内容 |
|---|---|
| **是什么** | 地块的产出倍率 |
| **公式** | `E = E_邻接 × E_幸福 × E_磨合 × (1 + 研究加成)` |
| **被什么决定** | 摆放位置、上季幸福度、磨合、研究 |
| **影响什么** | 产量、投入、经营费 |

**乘法关系，不是加法** —— 防止效率重复放大。

| 分量 | 公式 | 范围 |
|---|---|---|
| `E_邻接` | `1 + min(0.05 × 关联邻居数, 0.40)` | 1.00 – 1.40 |
| `E_幸福` | `H < 0.6 → 0.90`；否则 `0.90 + (H−0.6)×0.5` | 0.90 – 1.10 |
| `E_磨合` | 第 1/2/3 季起：`0.5 / 0.75 / 1.0` | 0.50 – 1.00 |
| 研究加成 | 每块研究地块 +1%，上限 +3% | 1.00 – 1.03 |

**取值范围**：理论最低 `1.0×0.9×0.5 = 0.45`，最高 `1.4×1.1×1.0×1.03 ≈ 1.59`。

### 邻接按"关联表"判定（不是同类型）

| 地块类型 | 关联地块类型 |
|---|---|
| 农业 | 农业、资源 |
| 资源 | 资源、工业 |
| 工业 | 工业、资源 |
| 服务 | 服务、农业、工业 |
| 研究 | 工业、高技术 |

每个关联邻居 +5%，上限 +40%。

> **服务是例外**：**任何**邻居都算、**不看类型**（荒地、工厂都算）；
> 但**率按服务自身的等级取**：一级 **+5%**、二级 **+7.5%**、三级 **+10%**（✅ 2026-10-16 改定），
> 且服务邻接**暂不封顶**（8 邻居、三级服务理论上限 +80%）。
> **别人给服务的加成**仍按关联表（服务认 服务/农业/工业，每个 +5%、封顶 +40%）。

### 效率影响什么

```
产量     = e × u × E      ← 随 E 放大
商品投入 = input × u × E  ← 随 E 放大
劳动     = d × u          ← 【不】随 E 放大
经营费   = 0.7c + 0.3c·u·E
```

> **含义**：效率高 = 同样的人一季处理更多批次，所以**原料和产出一起涨，人不涨**。
> 这就是为什么效率是这类游戏的核心追求。

## 其他在变的量

| 变量 | 公式 | 说明 |
|---|---|---|
| **现金** | 见流水账 | 收入 − 采购 − 工资 − 经营费 − 建设 |
| ~~**商品库存**~~ | **不存在**（✅ 2026-10-16：本项目**没有仓库**） | 产出**当季全部成为市场供给**（`X_t` = 本季产出 − 合同交付量），玩家**不申报卖出**；生产原料**生产时当场消耗**；建设物资**直接进工程**；买多了的口粮**结算时丢弃**。因此 `PlayerState` **不设库存字段** |
| **本季可用口粮** | 只来自本季**采购** | 产出不能吃；居民口粮必须在 `purchases` 里买，不买 → H = 0（基线 §3.3.6） |
| **市场价格** | `P_t = P0 + (B_t − X_t)/(s+d)`，`s = Es×Q0/P0`、`d = \|Ed\|×Q0/P0` | **结算时**按上季价买入、按本季价卖出；玩家阶段不扣款（✅ 2026-10-16）。**弹性 `Es`/`Ed` 15 个商品全齐**（✅ 2026-10-16，见基线 §8.5），所以 `P_t` 是**确定的数**。合同交付量从两侧剔除：卖方减 `X_t`、买方减 `B_t` |
| **GDP** | `有效产出价值 − 中间投入价值` | 用固定统计价 `P0` |
| **失信标记** | 违约事件驱动 | 影响补贴资格 |

## 三个变量的"手感"速查

| 你想…… | 动这个 | 后果 |
|---|---|---|
| 让人口涨 | 多建地、提高开工率 `u` | 岗位↑ → 人口↑ → 粮食需求↑ |
| 让粮食需求涨 | 升级地块（`ḡ`↑） | `m`↑ → 需求↑ **但产出也↑** |
| 让幸福度高 | 多投粮食（A/B，冲优秀要 ABCD） | `H`↑ → **下季**效率↑ |
| 让效率高 | 摆好邻接位置 + 喂饱居民 + 等磨合 | 产量↑，但原料消耗也↑ |
| 少烧钱 | 降低 `u` 或关停地块 | `u=0` 时经营费为 0，但也没产出 |
