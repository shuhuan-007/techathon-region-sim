## 六、服务

**0 → 0：不产任何商品，不采购任何物资，没有收入。纯基础设施。**

| 等级 | 商品投入 | `c` | `d` | 产出 | 邻接加成（给出去） |
|---|---|---|---:|---:|---|---|
| 1 | **无** | 20 | 3 | **无** | 给邻接 **+5%** |
| 2 | **无** | 32 | 3 | **无** | 给邻接 **+7.5%** |
| 3 | **无** | 48 | 2.5 | **无** | 给邻接 **+10%** |

**工资**：`16 / 单位劳动 / 季`
**建设物资**：新建 `H-J×1`；1→2 `H-J×1`；2→3 `H-J+×1`

**每季净支出** = `0.7c + 0.3c·u·E + d·u×16`（工资单价 16 见上），**收入 0**。
**回报体现在别的地块的产量上**——不体现在自己的账上。

> ⚠️ **服务不提供也不消耗食物**（✅ 2026-10-16 定案）：服务地块 `0→0`，**不产 A/B/C/D、也不吃 A/B/C/D**。
> 它的 `d` **要从粮食需求的 `L` 里剔掉**——`F_基准 / F_优秀` 只由**非服务地块**的岗位推出。
> 见 [规则基线 §3.3.6](../01-规范/规则基线.md)。

> ⚠️ **服务是邻接规则的唯一例外**：**任何**邻居都给它加成（**不看关联表**，荒地、工厂、农田一律算）。
> **但率按服务自身的等级取**：一级 **+5%**、二级 **+7.5%**、三级 **+10%**（✅ 2026-10-16 改定）。
> 而**别人给服务的加成**仍按关联表（服务认 服务/农业/工业，每个 +5%、封顶 +40%）。
> 编码时服务要**单独分支**，别把这张等级率表混进通用的 5% 表里；率表进 `config`。

```
E_邻接(服务) = 1 + rate(服务等级) × (所有相邻地块数)
rate: 1级 = 0.05   2级 = 0.075   3级 = 0.10
```

> ⚠️ **服务邻接暂不封顶**（⚠️ 初始估值，实测后再调）：其他地块一律封 +40%，
> 服务这里**暂时不做上限**——8 邻居、三级服务理论上限 **+80%**。是否回收成 +40% 见 §十二-3。

> **本轮改动说明（2026-10-16）**：此前表里三行都写"给邻接 **+10%**"、**不分等级**，
> 结果是**三级服务与一级服务收益完全相同，升级毫无意义**。
> 现改为**按服务自身等级取 5% / 7.5% / 10%**，升级服务第一次有了直接收益；
> "任何邻居都算（不看关联表）"这条**不变**。对齐 [规则基线 §3.6](../01-规范/规则基线.md)。

**作废的中间量**（代码里不要出现）：`Q_能力` / `q_售` / `D_实` / 服务费公式 `P_J = 400n/(16n+q_售)` / "渠道①服务代购"。

## 七、研究

**无商品产出。它提供全局效率加成。**

| 项目 | 值 |
|---|---|
| 商品投入（每季维护） | **无** |
| 经营费 `c` | 60 |
| 劳动 `d` | 2 |
| 产出 `e` | 0 |
| 工资 | 28 / 单位劳动 / 季 |
| **效果** | **每块正常运行的研究地块 → 全局效率 +1%** |
| **上限** | 同一玩家**封顶 +3%** |
| **不对自身加成** | ✅ |
| 关联邻居 | 工业、高技术 |

```
E = E_邻接 × E_幸福 × E_磨合 × (1 + 研究加成)
```

> ⚠️ **不能写成"每季永久累加"**——是"当前有 N 块研究在运行 → +min(N%, 3%)"。

## 十、邻接关联表（`E_邻接` 的唯一依据）

| 地块类型 | 关联地块类型 | 每邻居 | 上限 |
|---|---|---|---:|
| 农业 | 农业、资源 | +5% | +40% |
| 资源 | 资源、工业 | +5% | +40% |
| 工业 | 工业、资源 | +5% | +40% |
| 服务 | 服务、农业、工业 | +5% | +40% |
| **服务（给出去）** | **任意邻居** | **+5% / +7.5% / +10%**（按服务自身等级） | **暂不封顶** |
| 研究 | 工业、高技术 | +5% | +40% |

```
E_邻接 = 1 + min(0.05 × 关联邻居数, 0.40)          # 通用：关联表 + 5% / 封顶 +40%
E_邻接(服务) = 1 + rate(服务等级) × (所有相邻地块数)  # 例外：任何邻居 + 5%/7.5%/10%，暂不封顶
```

> ⚠️ **农业旁边的工业不加成**（关联表里没有）。
> 一块农业四周全是工业 → `N_关联 = 0` → `E_邻接 = 1.00`。

> ⚠️ **服务是唯一的例外行**（✅ 2026-10-16 改定）：任何邻居都算，**率按服务自身等级**取 5% / 7.5% / 10%，
> 且**暂不封顶**。除此之外所有地块都走上面那条通用式。见 §六 与 [规则基线 §3.6](../01-规范/规则基线.md)。

## 十一、地块的状态（不是类型）

除了"类型 × 等级"，地块还有**状态**：

| 状态 | 说明 |
|---|---|
| **空地** | 未开发，可建（没有"零级地块"概念） |
| **在建** | 有剩余工期，不产出 |
| **升级中** | 有剩余工期，不产出 |
| **正常运行** | 产出 / 提供加成 |
| **停工** | 缺料或维护不满足，`u` 降或为 0 |
| **装饰** | 前端美化用，不可点、不参与规则 |

> 在建 / 升级中 / 未运行的地块**不提供邻接加成**。
