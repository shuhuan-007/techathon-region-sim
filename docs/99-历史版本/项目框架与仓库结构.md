## 二、五条写法红线（**最重要**）

**功能上只做单人，代码结构按多人写。**
以后加联机时，**引擎核心一行不改**，只在外层套"服务器+请求队列"。

| # | 红线 | ✅ | ❌ |
|---|---|---|---|
| 1 | 玩家身份永远用 `player_id` 索引 | `state["players"]["p1"]["cash"]` | `state["cash"]` |
| 2 | 共享 / 私有分层 | 共享：市场价、曲线、政策、时钟 | 现金和价格塞同一个 dict |
| 3 | 收齐所有计划再一起结算 | `advance(plans: Dict[PlayerId, Plan])` | `advance(state, plan)` |
| 4 | 分配规则做成可替换策略函数 | 注入 `allocator` | 在 `market.py` 写死"先到先得" |
| 5 | 服务层只转发、不放规则 | `POST /state?player=p1` | 在路由里算价格 |

**第 1 条最贵**——把玩家状态摊在顶层，以后改多人几乎等于重写。

### 三处差别就是全部代价

```python
players: dict[str, PlayerState]        # ① players 字典
def f(state, player_id, ...)           # ② player_id 参数
def advance(state, plans: dict)        # ③ plans 字典
```

第一期 `assert len(plans) == 1` 就能跑，**但循环和签名按多人写**。

## 四、季度流水线（程序的"心脏"）

```python
def advance(state: GameState, plans: dict[str, Plan]) -> GameState:
    """第一期 assert len(plans)==1 即可，但结构按多人写。"""
    assert len(plans) == 1              # ← 第一期唯一的多余代码

    # 1. 准备
    for pid, plan in plans.items():
        apply_plan(state, pid, plan)

    # 2. 效率（服务走独立分支）
    for pid, plan in plans.items():
        for plot in state.players[pid].plots.values():
            plot.efficiency = compute_efficiency(state, pid, plot)

    # 3. 人口与粮食需求
    for pid in plans:
        update_population(state, pid)

    # 4. 期初采购（按上期价）
    for pid, plan in plans.items():
        do_purchases(state, pid, plan)

    # 5. 生产
    for pid, plan in plans.items():
        run_production(state, pid, plan)

    # 6. 建设推进
    for pid in plans:
        advance_construction(state, pid)

    # 7. 市场结算（共享资源，一起结算）
    settle_market(state, allocate_proportional)

    # 8. 粮食结算 → H    ★ 必须在市场之后
    for pid in plans:
        settle_food(state, pid)

    # 9. 税收 / GDP
    for pid in plans:
        settle_taxes(state, pid)

    # 10. 结转
    state.world.quarter += 1
    return state
```

**顺序铁律**：
- 第 4 步：本季产出**不能**倒填本季已开始的消费
- 第 8 步**必须**在第 7 步之后

## 五、可替换的分配策略（红线 4）

```python
def allocate_proportional(demand: dict[str, float],
                          supply: float) -> dict[str, float]:
    """默认：按比例分配共享资源。"""
    total = sum(demand.values())
    if total == 0:
        return {}
    return {k: supply * v / total for k, v in demand.items()}

def settle_market(state, allocator=allocate_proportional):
```

## 六、服务层（只转发）

```python
@app.get("/state")
def get_state(player: str = "p1"):
    return serialize(state, player)      # ← 只序列化，不算

@app.post("/advance")
def post_advance(player: str = "p1", plan: Plan = Body(...)):
    plans = {player: plan}               # ← 单人的唯一体现
    engine.advance(state, plans)
    return serialize(state, player)
```

> **铁律**：路由里**不算价格、不改状态、不做插值**。全部交给 `engine/`。
