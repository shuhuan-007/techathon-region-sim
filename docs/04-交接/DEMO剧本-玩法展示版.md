# DEMO 剧本 · 玩法展示版

> 本文是「中期存档 + 一集 DEMO」任务的**剧本设计稿**。
> 与 [`演示操作稿.md`](演示操作稿.md)（5 分钟路演版）不同：那是给现场评委看的快节奏演示，
> **本文是给"录一集"用的完整剧本**——20 季浓缩成 12 季展示，每季把"完整玩法闭环"走完一遍。

---

## 〇、设计原则（先背下来）

1. **不求 GDP 最大化**——求"玩家真实会做什么"。包括错判、AI/玩家分歧、临时改计划、用工具自救。
2. **每一季都走完 5 步循环**，但每一步的"戏份"随剧情变化：
   ```
   ① 看月报（/api/state + /api/narratives）   ← 上季结果
   ② 问 AI（/api/ai/advise）                  ← AI 给方向
   ③ 起草 + 自动落表 + 自动试算（隐式）        ← AI 帮玩家填单
   ④ 手改细节（点格子、改数量）                ← 玩家有自己的想法
   ⑤ ▶ 推进本季度                            ← 一键搞定
   ```
   > ⚠️ 前端没有"校验""试算"独立按钮（2026-10-18 重构后刻意如此）。
   > "试算"是玩家改表单时 schedulePreview 自动跑的，玩家感知是顶栏预览数字变化。
3. **AI 秘书有三次戏份**：answer（问机制）/ plan（要 AI 起草）/ 拒绝 AI（玩家一意孤行）。
   三种形态都要演到，这是项目"AI 是秘书不是老板"的最好证明。
4. **20 季浓缩成 12 季展示**：用"中期存档"在第 12 季把剧本切到分支，
   从 Q12 存档分出 A/B 两条线，让观众看到"存档分支"的玩法价值。
5. **每季屏幕要出现的关键 UI 元素**都列在剧本里，录屏照单抓即可。

## 一、剧本大纲（12 季展示 + Q13-Q20 后台跑完）

### 第一幕 · 白手起家（Q1-Q3）—— 教观众怎么玩

| 季 | 标题 | 玩法展示重点 | 剧情 |
|---|---|---|---|
| **Q1** | 第一笔投资 | 建造 + 开局半价 + submit 不扣款 | 摆 4 块农业 + 看完开工 → 扣款 456 → 现金 744 |
| **Q2** | AI 出场（answer 分支） | 问机制："为什么我的效率 E 不到 1？" | AI 答规则原文，玩家听完后明白"上一季 H" |
| **Q3** | AI 起草（plan 分支） | "帮我起草一份再扩 2 块农业" | AI 起草 + 落表 + 玩家点推进 |

**存档点**：Q3 结束存 `demo-a@q3-tutorial-done`

### 第二幕 · 决策纠结（Q4-Q8）—— 真玩家会遇到的戏剧性

| 季 | 标题 | 玩法展示重点 | 剧情 |
|---|---|---|---|
| **Q4** | AI / 玩家分歧 | AI 说"继续扩农业"，玩家想"试高精尖" | **玩家拒绝 AI**，自建研究地块（走自己的路） |

| **Q7** | 押注未来 | 高精尖 G 厂开工（8 季工期） | 玩家赌了一把 |
| **Q8** | 中途盘点 | 看历史报告（/api/report 多次回看） | 现金紧张，研究地块还没回本，玩家纠结 |

- Q5 结束存 `demo-a@q5-food-crisis`

### 第三幕 · 收割与反思（Q9-Q12）—— 终局的爽感

| 季 | 标题 | 玩法展示重点 | 剧情 |
|---|---|---|---|
| **Q9** | 反弹 | H 回到 0.65 | 口粮链闭合 |

| **Q11** | 现金爆炸 | 现金从 800 → 1500+ | 玩家飘了，多建了一些 |

**存档点**：Q12 结束存 `demo-a@q12-before-finale`

### 分支验证（后台跑：Q13-Q20）

**核心演示**：B 线 `demo-b` 从 `demo-a@q12-before-finale` 恢复，**用和 A 线一模一样的 Plan** 跑 Q13-Q20。
> ✦ 断言：B 线每季现金 / GDP / H 与 A 线**完全一致，分毫不差**。

录屏时，A 线也跑 Q13-Q20。最后镜头并排放 A 线 20 季财报曲线和 B 线 20 季财报曲线。

### 示例：Q1 · 第一笔投资

| 步骤 | 屏幕出现 | 玩家说什么 |
|---|---|---|
| ① 看月报 | 开局啥都没有，月报 modal 显示"还没有结算过" | "好，我现在 1200 现金，要从零开始" |
| ② 问 AI（answer） | AI 答："开局建议每类前 3 块半价，建议先点 3 块农业 + 1 块备用" | 玩家点头 |
| ③ （手填，不走起草） | 玩家在左栏点 4 个格子，选产出"A" | "我自己点，让 AI 看看我怎么布" |
| ④ 玩家手改 | 把第 4 块也点上（明知要花 144 而非 104） | "前 3 块半价，第 4 块原价——我想要 4 块连片，值" |
| ⑤ ▶ 推进 | 流水涌：扣 456 → 现金 744 → 进入第 2 季 | "提交不扣款是真的——点结算才扣" |

**存档点**：无（Q1 还不值得存档）。

| | suggested_plan 自动落表，左栏表单多了 2 块虚线建造标记 | |
| ③ 自动试算 | 顶栏"本季计划扣 208｜结算后约 1092" | "AI 真能帮我填单" |

### 示例：Q4 · AI/玩家分歧（最重要的一幕）

| 步骤 | 屏幕出现 | 玩家说什么 |
|---|---|---|
| ① 看月报 | 现金还不错，4 块农业稳定产出 | "我现在该往哪个方向走？" |
| ② 问 AI（plan，**玩家打算拒绝**） | 玩家打："帮我起草下季计划" | |
| | AI 回："建议继续扩农业，再增 3 块 A → 现金回报周期 2 季" | |
| ③ （不采纳，丢弃） | 玩家点"取消"，清空草稿 | "AI 是保守派——我想试高精尖路线" |
| ④ 玩家手填 | 玩家点 (0,1) (1,1) 摆研究地块 + 投研究 × 3 | "G 厂 8 季工期，现在不投等什么时候？" |
| ⑤ ▶ 推进 | 流水涌：研究地块开工（不降现金），等待回报 | "赌一把" |

**存档点**：无

> ✦ **这一幕是整集 DEMO 的戏剧性高峰**：AI 是秘书不是老板，玩家可以一意孤行。
> 后续 Q5-Q8 的"粮食危机+押注未来"，都因为玩家这次拒绝 AI 建议而发生——这就是"玩家主导"的游戏性。

## 四、推进会用的 HTTP 接口清单（给工具脚本看的）

```
POST   /api/new_game         {game_id, player_id}
GET    /api/state            ?game&player&narratives=0|1
GET    /api/map              ?game&player
GET    /api/report           ?game&player
GET    /api/narratives       ?game&player
GET    /api/build_options
POST   /api/ai/advise        {game, player, question, draft, current_plan, mode}
POST   /api/submit           {game, player, plan}
POST   /api/simulate         {game, player, plan}        ← 仅"仅试算"工具用，剧本不主动调
POST   /api/end_quarter      {game, player}
POST   /api/next_quarter     {game, player}              ← 2026-10-18 起前端自动调，无需玩家点
POST   /api/save_slot        {game, player, slot}        ← 新增（本子代理实现）
POST   /api/load_slot        {slot_id, as_game_id}       ← 新增
GET    /api/slots            ?game                       ← 新增
GET    /api/finale           ?game&player
```
